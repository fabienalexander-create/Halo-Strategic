empty tracker, ready for the first 5 buyer conversations. Add one row per
buyer as Discovery calls happen. Detail from each call lives in that
buyer's own qualification worksheet (`hvac-buyer-qualification-worksheet`

patterns are visible once there are several rows to compare.

## How to use this

1. Run a Discovery call using `hvac-buyer-discovery-questionnaire-DRAFT.md`.
2. Fill a fresh copy of `hvac-buyer-qualification-worksheet-DRAFT.md` for
   that buyer.
3. Add one summary row below.
4. Once 5 rows exist, look across them for the actual market answer to
   "what's a fair PPL" and "what does exclusivity need to look like" —
   don't decide those from a single conversation.
