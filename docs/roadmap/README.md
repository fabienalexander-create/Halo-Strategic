# Roadmap Library

Design documents for future Halo capabilities that are deliberately **not** scheduled yet, a library of well-thought-through future systems, not a queue of upcoming work.

Distinct from `docs/ROADMAP.md`, which tracks Halo's actual sprint plan (what's being built now, in what order). Documents here are the opposite: capabilities worth designing in detail precisely *because* they're not being built yet, so that when Halo is ready for one, the vision already exists and implementation can be deliberate rather than a rebuild-from-memory of an old conversation.

## Rule

Every document in this folder is planning only. **No implementation begins from a document here until it's explicitly pulled out, approved, and scheduled into `docs/ROADMAP.md` or a numbered sprint.** A document sitting in this folder is not a green light.

- [`CRM_AUTOMATION_ROADMAP.md`](CRM_AUTOMATION_ROADMAP.md) — future enquiry automation architecture (CRM, email automation, AI enquiry briefs, founder dashboard, proposal generation, knowledge base). Phase 1 (manual, Netlify Forms → email → Fabien) is the only phase currently live.
